# Spectral Sky

A physically based sky HDRI creator that runs in the browser: spectral atmosphere, volumetric clouds, sun and moon, stars, mountains, and exports for lighting and comp (EXR HDRIs, cloud-shadow gobos, a haze lookup for Nuke).

Open it at **https://x14halo.github.io/hdri/** — a desktop browser with a dedicated GPU (Chrome or Edge) works best.
